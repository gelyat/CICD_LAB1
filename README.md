# Лабораторная работа №1: Задача 2.25

## Описание задачи
На шахматной доске расположены Белый король, черная ладья и слон.
Определить, есть ли угроза королю, если да, то от кого?
- Слон ходит по диагонали.
- Ладья ходит по горизонталям и вертикалям.

## Структура файлов
- `main.cpp` — исходный код программы на C++17.
- `report.md` — отчет по 11 пунктам (Markdown).
- `report.tex` — исходник отчета в LaTeX.
- `flowchart.png` — изображение блок-схемы алгоритма.

## Сборка и запуск на Windows


### Windows

#### Вариант 1: Через консоль (MinGW / GCC / g++)
1. Откройте командную строку (`cmd`) или PowerShell в папке с файлом `main.cpp`.
2. Скомпилируйте программу:
   ```cmd
   g++ -std=c++17 main.cpp -o main.exe
   ```
3. Запустите:
   ```cmd
   main.exe
   ```


#### Вариант 2: Через Visual Studio (MSVC / Developer Command Prompt)
```cmd
cl /EHsc /std:c++17 main.cpp
main.exe
```

#### Вариант 3: Через IDE (Visual Studio, CLion, Code::Blocks, Dev-C++)
1. Создайте новый консольный проект C++ (или откройте `main.cpp`).
2. Нажмите **Сборка и запуск** (в Visual Studio: `Ctrl + F5`).

---

### Linux / macOS

1. Откройте терминал в папке проекта.
2. Скомпилируйте:
   ```bash
   g++ -std=c++17 -Wall -Wextra main.cpp -o main
   ```
3. Запустите:
   ```bash
   ./main
   ```
